# FOC 速度环调参手册

## 参数表

| 参数 | 宏/变量 | 默认值 | 范围 | 说明 |
|------|---------|--------|------|------|
| 加速斜率 | `FOC_MAX_ACCEL_RPM_PS` | 10000 | 1000-50000 | PI 目标斜坡，单位 RPM/s |
| 减速斜率 | `FOC_MAX_DECEL_RPM_PS` | 20000 | 1000-50000 | 制动时更快降速 |
| P 增益 | `FOC_SPEED_KP` | 0.02 | 0-100 | 增量式 P：`Kp × Δe` |
| I 增益 | `FOC_SPEED_KI` | 2.0 | 0-100 | 增量式 I：`Ki × e × dt` |
| Vq 限幅 | `FOC_VQ_LIMIT_FRAC` | 0.70 | 0-0.95 | 最大输出电压占 Vbus 比例 |
| 速度死区 | `FOC_SPEED_DEADZONE_RADPS` | 0.1 | 0-10 | 误差死区 (rad/s)，约 1 RPM |
| 速度估滤波 | `g_as5047p_lp_alpha` | 0.4 | 0.001-1.0 | 速度低通 α，越大响应越快、噪声越大 |
| 速度估样本数 | `g_as5047p_speed_avg_samples` | 1 | 1-100 | 移动平均窗口，1=不平均 |
| 速度零死区 | `g_as5047p_speed_zero_deadband_rpm` | 2.0 | 0-20 | 低于此 RPM 强制为 0 |
| 堵转速度阈 | `FOC_STALL_SPEED_RADPS` | 5.0 | 1-50 | 低于此速度判定堵转 (~48 RPM) |
| 堵转超时 | `FOC_STALL_TIMEOUT_S` | 0.5 | 0.1-5.0 | 堵转持续触发时间 |

## 加速调优

目标 0→2000 RPM 时间 = `2000 / FOC_MAX_ACCEL_RPM_PS`

| RPM/s | 0→2000 时间 | 效果 |
|-------|------------|------|
| 2000 | 1.0s | 极柔和，起步慢 |
| 5000 | 0.4s | 平滑，适合低速 |
| **10000** | **0.2s** | **当前默认，快速响应** |
| 20000 | 0.1s | 激进，可能打滑 |
| 50000 | 0.04s | 暴力，必定打滑/过流 |

**方法**：在 FOC 测试页面起跑，观察实际转速跟踪目标的滞后。如果目标爬升时实际转速有大幅过冲 → 斜率太大，减小。

## 抗扰调优

外力扰动后恢复速度取决于 **Kp + Ki 组合**：

- **Kp 决定瞬时响应**：Kp 越大，误差变化立刻输出更大的 Vq
- **Ki 决定持续出力**：Ki 越大，积分器更快累积到克服摩擦的水平
- **Vq_limit 决定最大出力**：如果限幅太低，PI 算出的大输出被截断

**测试方法**：FOC 测试模式，设定 1000 RPM，用手给轮子阻力然后放开：
- 放开后转速飙升 → Kp 太大，减小
- 放开后回落到目标很慢 (>0.5s) → Ki 太小，增大
- 稳态有微小抖动 → 死区太小，增大 `FOC_SPEED_DEADZONE_RADPS`
- 稳态有持续偏差 → Ki 太小或死区太大

## 减速度调优

`FOC_MAX_DECEL_RPM_PS` 独立于加速斜率，默认 20000 RPM/s（2 倍加速斜率）。

- 如果预转弯时刹车太猛导致点头 → 减小
- 如果刹车不够快导致冲过弯道 → 增大

## 常见震荡原因

| 症状 | 原因 | 修正 |
|------|------|------|
| 无负载正常、带载震荡 | 积分器饱和 → 恢复慢 → 限幅循环 | 减小 Ki，增大 Vq_limit |
| 低速段抖动 | 速度估算噪声 + 死区太小 | 增大死区或增大 LP α |
| 高速段抖动 | 编码器噪声 + 毛刺保护不足 | 检查 `FOC_SPEED_EST_GLITCH_ENABLE` |
| 停车后持续嗡嗡响 | 积分器未清零 | 正常运行，停机路径会清除 |
| 堵转误触发 | 负载太大或阈值太低 | 增大 `FOC_STALL_SPEED_RADPS` 或 `FOC_STALL_TIMEOUT_S` |

## 速度估算管线的延迟

```
编码器 (10kHz) → 角度差累加 (1kHz子采样) → 移动平均 → LP滤波 → PI
延迟:          ~0                          ~1ms          ~N*1ms    ~2-5ms
```

最坏延迟约 `avg_samples × 1ms + LP时间常数`。要减小延迟：
1. `g_as5047p_speed_avg_samples = 1` (不做平均)
2. `g_as5047p_lp_alpha = 0.6-0.8` (更快跟踪)
3. 代价：速度信号噪声增大，PI 需要更强滤波(降低 Kp)来补偿
